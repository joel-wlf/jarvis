Du brauchst einen Raspberry Pi (oder einen anderen 64-Bit-Linux-Rechner) mit Docker und Docker Compose. Hardware-Hinweise stehen in der [Raspberry-Pi-Anleitung](./raspberry-pi.mdx).

## 1. Installieren

### Mit dem Installer

<InstallCommand />

Der Installer holt die fertigen Images, legt den Projektordner an und startet den Admin-Dienst.

### Aus dem Quellcode bauen

Wenn du alles selbst auf dem Gerät bauen willst:

```bash
git clone https://github.com/joel-wlf/jarvis.git ~/jarvis && cd ~/jarvis
docker compose up -d admin
docker compose logs admin        # zeigt den Einrichtungscode
```

Der erste Bau dauert auf einem Pi 4 eine Weile.

## 2. Einrichtungsassistent

Öffne `http://<adresse-des-pi>:8080` in einem Browser im selben Netz. Gib den **Einrichtungscode** aus dem Admin-Log ein und lege ein Admin-Passwort fest.

Der Assistent fragt:

1. Deinen Namen (für Zusammenfassungen und Profile).
2. Einen KI-Anbieter samt Schlüssel (optional, mit Live-Test). Ohne läuft alles lokal und langsamer.
3. Datenschutz-Ausschlüsse: Chats, deren Name diese Wörter enthält, gehen nie an die KI. Setze das vor dem ersten Start mit Schlüssel.
4. Welche Funktionen laufen sollen (Themen-Sortierung, Bildbeschreibung, Aktionen).
5. Optional einen Cloudflare-Tunnel, damit App und Claude dich auch unterwegs erreichen.

Danach erzeugt er alle Passwörter und Tokens selbst, baut und startet die Dienste und zeigt den nächsten Schritt.

## 3. WhatsApp verknüpfen

Der Assistent endet auf der WhatsApp-Seite. Sie zeigt den **QR-Code** im Browser, oder einen **Kopplungscode**, wenn du deine Telefonnummer eingibst.

Am Handy: WhatsApp → Einstellungen → Verknüpfte Geräte → Gerät hinzufügen → scannen.

Danach schickt das Handy den Verlauf in Batches. Das kann einige Minuten dauern. Halte das Handy online und WhatsApp geöffnet. Wie viel Verlauf kommt, entscheidet WhatsApp.

<Callout title="Verknüpfen im Terminal">
Ohne Weboberfläche: `docker compose logs -f wa-ingest` zeigt den QR-Code im Log.
</Callout>

## 4. App koppeln

Installiere die Jarvis-App (oder öffne die Web-Version unter der Admin-Adresse). Auf dem Verbindungsbildschirm hast du zwei Wege:

- **Code scannen.** Öffne in der Admin-Oberfläche die Geräteseite, zeige den Kopplungscode an und richte die Kamera der App darauf.
- **Adresse und Passwort.** Gib deine öffentliche Adresse ein (zum Beispiel `https://jarvis.example.com`) und das Besitzer-Passwort, das du gewählt hast, und tippe auf Verbinden.

Details stehen unter [Die App](./app.mdx).

## 5. Claude verbinden

Trage `https://jarvis.example.com` in Claude als eigenen Connector ein. Siehe [Claude verbinden](./connect-claude.mdx).

## Prüfen, ob es läuft

```bash
docker compose ps
docker compose exec postgres psql -U jarvis -c "select count(*) from messages"
```

Die Zahl wächst, solange der Verlauf importiert wird. Sprachnachrichten werden im Hintergrund transkribiert.
