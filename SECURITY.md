# Sicherheit

Jarvis verarbeitet private Chats und kann in deinem Namen senden. Bitte melde Sicherheitslücken **nicht** als öffentliches Issue, sondern über „Report a vulnerability“ (GitHub Security Advisories) im Repository.

Hinweise zum sicheren Betrieb stehen im README-Abschnitt „Sicherheit“. Committe nie `.env`, Backups oder das Volume `wa-auth`.
